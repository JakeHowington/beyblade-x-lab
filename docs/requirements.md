
# Software Requirements

## 1. Project Overview

    1.1 Purpose

        Beyblade X Battle Lab is a web application designed to provide user with a full
        catalog of all current Beyblade X parts, the ability to document their ownership of those parts, 
        creating custom combinations from parts that are owned or in catalog, recording and analyzing battle data.
